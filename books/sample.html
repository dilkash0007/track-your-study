Track Your Study - PDF Books

This is a placeholder page. To use the Books feature with pre-loaded PDFs, you'll need to add actual PDF files.

How to Add PDF Books

To add pre-loaded PDF books to your application:

  1. Place PDF files in the /public/books/ directory
  2. Make sure the filenames match those referenced in index.json
  3. Alternatively, update the index.json file to match your actual PDF filenames

Expected Files

According to index.json, the system is looking for these files:

├── learning-javascript.pdf
├── web-design-fundamentals.pdf
├── python-data-science.pdf
├── modern-react.pdf
└── calculus-simple.pdf

User-Uploaded PDFs

In addition to pre-loaded PDFs, users can upload their own PDF files. These files are:

  • Stored in the browser's localStorage
  • Combined with pre-loaded PDFs in the book list
  • Preserved between sessions on the same device

Troubleshooting

If you encounter issues with PDF loading:

  • Ensure the PDF files are valid and not corrupted
  • Check that filenames match exactly what's specified in index.json
  • Verify the PDFs are placed in the correct directory (/public/books/)
  • Check browser console for any JavaScript errors
