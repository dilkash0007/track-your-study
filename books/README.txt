PDF BOOK PLACEHOLDER

This folder contains placeholder entries for pre-loaded PDF books.

To use this feature properly:
1. Place actual PDF files in this directory with filenames matching those in the index.json file
   (e.g., learning-javascript.pdf, web-design-fundamentals.pdf, etc.)

2. Alternatively, modify the index.json file to match the actual PDF files you place here

All PDF files must be valid PDF documents. The book reader will display error messages 
for missing or corrupted files.

The user can also upload their own PDF files, which will be stored in the browser's
local storage and combined with these pre-loaded books.
